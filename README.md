# Funship

Little apps made for one family at a time.

**Live demo:** https://nweinberg97.github.io/Funship/

- `index.html`: the clickable demo (built from `prototype/`, served by GitHub Pages)
- `docs/PRD.md`: the product requirements document
- `prototype/`: the demo's source. Edit there, then run `python3 prototype/build.py`. See `prototype/README.md`.
